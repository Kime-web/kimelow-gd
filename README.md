# Kimelow.gd — Geometry Dash Tracker

## Запуск
1. Распакуй архив в отдельную папку.
2. Открой `index.html` в браузере (лучше Chrome/Edge).
3. Нажми «Добавить уровень» и начни вести свой Death Tracker.

## Что добавлено
- Death Tracker с категориями «Прохожу», «Планирую» и «Завершил».
- Лучший процент, целевой процент, общее число попыток и сессии по датам.
- Журнал смертей с процентом и подсчётом частоты (например, 60% × 2).
- История личных рекордов и простой график процентов.
- Поля сложности, ID, ссылки на уровень, видео и личного комментария.
- Кнопка «Я прошёл!» с коротким победным звуком.
- Звуковой отклик при нажатии кнопок (генерируется браузером, аудиофайлы не нужны).
- Цели, статистика, список завершённых уровней и отдельный список собственных уровней.
- Поиск, мобильная навигация, подтверждение удаления.
- Автоматическая миграция старых данных с предыдущей версии сайта.

## Сохранение данных
Данные сохраняются в `localStorage` этого браузера и устройства. Облачной синхронизации пока нет. Не очищай данные сайтов в браузере, если хочешь сохранить записи. Для переноса на другое устройство в будущем понадобится экспорт/импорт или серверная база.

## Звуки
Браузер может начать воспроизводить звуки только после первого взаимодействия с сайтом. Звук создаётся через Web Audio API. Его можно отключить в настройках браузера/системы.

## Примечание
Вся статистика пустая до тех пор, пока ты сам не добавишь свои уровни и рекорды. Это статический сайт без серверной части.


## Demon List (v3)
- Встроенный раздел Demon List в боковом меню.
- Top 150 запрашивается из Pointercrate API при открытии сайта; список можно обновить.
- Extreme / Insane / Hard Demon ищутся по названию через GDBrowser API. Эти вкладки не являются отдельным глобальным рейтингом.
- Кнопка «В трекер» добавляет уровень в Death Tracker с категорией «Планирую».
- Для работы внешних API нужно интернет-соединение. Если браузер блокирует API или сервис временно недоступен, раздел показывает ошибку и ссылки на официальные сайты вместо выдуманных данных.
- Открой index.html в браузере. При некоторых локальных настройках браузера внешние API могут блокироваться; в таком случае открой сайт через локальный статический сервер.


## Multi-page version v4
Сайт разделён на отдельные HTML-страницы, связанные общей боковой навигацией:
- `index.html` — обзор и основной редактор.
- `demon-list.html` — отдельная страница Demon List.
- `tracker.html` — сводка Death Tracker.
- `completed.html` — пройденные уровни.
- `my-levels.html` — собственные уровни.
- `progress.html` — сводка целей и статистики.
- `about.html` — профиль / информация.
Общие стили находятся в `styles.css`. Demon List использует Pointercrate API для Top и GDBrowser для поиска категорий; внешние API требуют интернет и могут быть недоступны из-за сетевых ограничений.
Важно: текущая версия хранит записи в localStorage, поэтому данные не синхронизируются между устройствами. Страницы с отдельными сводками читают локальные данные браузера; основной редактор остаётся на `index.html`.

# Kimelow.gd v8

- Главная стала страницей обзора: Demon List и Death Tracker теперь только в соответствующих отдельных HTML.
- Уровень добавляется внутри tracker.html через «Добавить новый уровень».
- В карточке уровня «Загрузить фото» позволяет выбрать JPEG, PNG или WEBP с устройства. Изображение уменьшается и сжимается, затем сохраняется в данных браузера; «Ссылка на обложку» принимает прямой URL картинки, пустое значение удаляет обложку.
- Картинка «Мой путь в GD» заменена на gd-journey-v8.webp.
- Остальные разделы сохранены.

Важно: localStorage ограничен браузером (часто около 5 МБ); массовая загрузка тяжёлых обложек может исчерпать место. В онлайн-режиме Supabase обложки сейчас хранятся как поля записей и для полноценного хостинга множества пользователей желательно вынести медиа в Supabase Storage. Для аккаунтов Supabase требуется настройка проекта из инструкции v5.

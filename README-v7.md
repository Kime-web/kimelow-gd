# Kimelow.gd v7

На базе оригинальной multipage v6. Откройте index.html.

- `tracker.html`: каждая запись Start Pos имеет кнопку × удаления с подтверждением.
- Главная страница: удаление Start Pos прямо из карточки.
- `runs.html`: отдельная страница для смертей с 0% (формат `0-56`, `0-45x2`, `0-98x4`), выбор уровня, удаление записей.
- «Мой путь в GD»: обновлённая картинка игрового мира.
- Старые данные `kimelow-gd-hub-data-v2` не перезаписываются при запуске.
- Данные сохраняются локально; аккаунты требуют настройки Supabase из README-v5.md.
- Записи `zeroRuns` хранятся отдельно от обычных рекордов, смертей и Start Pos.
